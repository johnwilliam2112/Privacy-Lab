# ◈ Privacy Lab — آزمایشگاه حریم خصوصی و اثرانگشت مرورگر

[English](README.md) · **فارسی** · [中文](README.zh-CN.md)

یک Cloudflare Worker تک‌فایل با ۴۰ صفحه ابزار که نشان می‌دهد یک وب‌سایت چه چیزهایی درباره مرورگر و شبکه شما می‌تواند بفهمد: IP و فراداده‌های درخواست، سطوح اثرانگشت‌گیری (Canvas، WebGL، صدا، فونت‌ها و…)، سیگنال‌های حریم خصوصی و هدرهای امنیتی. بدون وابستگی، بدون پایگاه داده و بدون ذخیره هیچ داده‌ای.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/YOUR_USERNAME/privacy-lab-worker)

> عبارت `YOUR_USERNAME/privacy-lab-worker` را در پیوند دکمه با مخزن **عمومی** GitHub خودتان جایگزین کنید.

## ویژگی‌ها

- **۴۰ ابزار**، هر کدام در یک صفحه؛ نتایج با باز شدن صفحه خودکار اجرا می‌شوند.
- **۳ زبان**: English، فارسی (چیدمان راست‌به‌چپ)، 中文. دکمه‌ها، هشدارها و پیام‌ها ترجمه شده‌اند.
- **محلی‌محور**: آزمون‌های مرورگری درون مرورگر شما اجرا می‌شوند؛ فقط صفحه IP/درخواست از داده‌های درخواست Cloudflare استفاده می‌کند.
- **صادقانه درباره محدودیت‌ها**: آزمون‌های TLS، HTTP/2، QUIC و TCP/IP توضیح می‌دهند که Worker دست‌دهی خام را نمی‌بیند و اثرانگشت جعلی نمی‌سازند.
- بدون کوکی، بدون ابزار تحلیل، بدون اسکریپت شخص ثالث.

| گروه | ابزارها |
|---|---|
| شبکه / سرور | IP، TLS، HTTP/2، QUIC، TCP/IP، اطلاعات اتصال |
| اثرانگشت مرورگر | جاوااسکریپت، WebRTC، Canvas، WebGL، فونت‌ها، صدا، صداهای گفتار، صفحه‌نمایش، ClientRects، Client Hints، خلاصه اثرانگشت، کوئری‌های رسانه CSS، قابلیت‌ها، حسگرها، دستگاه‌های رسانه |
| حریم خصوصی | مکان‌یابی، مجوزها، حافظه و کوکی‌ها، مسدودسازی ردیاب‌ها، اسکریپت‌های شخص ثالث، عدم ردیابی، فیلترهای محتوا، افزونه‌ها |
| امنیت | HTTPS و هدرها، CSP، CORS، سیاست Referrer، Permissions-Policy، اعتبارنامه‌ها، WebAuthn، محتوای ترکیبی، ایزوله‌سازی میان‌مبدأ، WebGPU، موتور JS و Intl |

## انتخاب زبان

به هر نشانی `?lang=en`، `?lang=fa` یا `?lang=zh` اضافه کنید یا از انتخاب‌گر زبان در سربرگ استفاده کنید. در غیر این صورت `Accept-Language` مرورگر و سپس انگلیسی به کار می‌رود. هیچ کوکی‌ای تنظیم نمی‌شود و پیوندها پارامتر `?lang=` را نگه می‌دارند.

## API

| مسیر | توضیح |
|---|---|
| `/api/request` | JSON: سرآیندهای درخواست و فراداده Cloudflare که Worker می‌بیند |
| `/api/ip` | JSON: IP مشاهده‌شده، کشور، شهر، ASN |

## محدودیت‌ها

Cloudflare اتصال TCP/TLS/HTTP/QUIC بازدیدکننده را در لبه خود پایان می‌دهد، بنابراین Worker نمی‌تواند بسته‌های خام، ClientHello در TLS (‏JA3/JA4)، فریم‌های HTTP/2 یا دست‌دهی QUIC را ببیند. موقعیت‌یابی IP تقریبی است. آزمون‌های تشخیصی (ردیاب‌ها، افزونه‌ها، فیلترهای محتوا) در حد تلاش هستند و «قطعی نیست» علامت می‌خورند.

## شخصی‌سازی

- **افزودن زبان**: آن را به `LANGS` اضافه کنید و یک دیکشنری `I.<code> = { ... }` در انتهای `worker.js` بنویسید. کلیدهای ناموجود به انگلیسی برمی‌گردند.
- **افزودن ابزار**: شناسه آن را به `TOOLS`، یک صفحه به `pages` و متن‌ها (`<id>.t`، `<id>.d` و…) را به دیکشنری‌ها اضافه کنید.
